# キャンパス青空ジム

大学生の日常に運動のきっかけをつくる、スマートフォン向けの試作Webサイトです。
研究活動の一環として制作したもので、身体活動を増やす効果はまだ検証されていません。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページの土台 |
| `style.css` | デザイン（色・文字・レイアウト） |
| `menus.js` | 運動メニューのデータ。**メニューの追加・修正はここだけ** |
| `app.js` | 画面の切り替え、タイマー、イラストなどの処理 |

ビルド作業や外部ライブラリは不要です（文字表示のみ Google Fonts を使用）。

## GitHub Pagesで公開する手順

1. GitHubにログインし、右上の「+」→「New repository」でリポジトリを作成します（例：`campus-aozora-gym`、Public）。
2. 作成したリポジトリで「Add file」→「Upload files」を選び、この4ファイルと `README.md` をドラッグして「Commit changes」を押します。
3. リポジトリの「Settings」→「Pages」を開き、「Source」を「Deploy from a branch」、Branch を `main`・フォルダを `/ (root)` にして「Save」を押します。
4. 1〜2分ほどで `https://<ユーザー名>.github.io/campus-aozora-gym/` が公開されます。

## ポスター用QRコードのURL

| 設置場所 | QRコードにするURL |
| --- | --- |
| 通常 | `https://<ユーザー名>.github.io/campus-aozora-gym/` |
| エレベーター付近 | `https://<ユーザー名>.github.io/campus-aozora-gym/?from=elevator` |

`?from=elevator` 付きでアクセスすると、トップに「1フロアだけ階段を使う」の案内が表示され、階段利用が一覧の先頭に並びます。
同時に「体調が優れないときはエレベーターで大丈夫」という案内も必ず表示されます。

## 画面の構成

- `#/` トップ（時間から選ぶ／運動の種類から選ぶ）
- `#/time/short`・`#/time/long` 時間別の一覧
- `#/cat/walk`・`stretch`・`stairs`・`strength` 種類別の一覧
- `#/menu/<id>` 運動の詳細（やってみる／完了した／別の運動を探す）
- `#/about` このサイトについて・プライバシー

## 運動メニューの編集

`menus.js` の `MENUS` 配列に項目を追加・修正してください。各項目の意味はファイル冒頭のコメントに書いてあります。
医療上の効果や消費カロリーなど、根拠のない数値は書かないでください。

## 研究用の計測について（未実装）

この試作版は**利用データを一切収集・送信していません**。「このサイトについて」ページにもそう明記しています。

`app.js` には次のタイミングで呼ばれる計測フック `track()` だけを用意しています。

| イベント名 | タイミング | 送られる情報 |
| --- | --- | --- |
| `menu_view` | 運動の詳細を開いた | メニューID・カテゴリー |
| `category_view` | 種類別の一覧を開いた | カテゴリー |
| `try_click` | 「やってみる」を押した | メニューID・カテゴリー |
| `done_click` | 「完了した」を押した | メニューID・カテゴリー |

計測を導入する場合は、`app.js` より前に読み込むスクリプトで次の関数を定義すると、上記イベントがそこに渡されます。

```html
<script>
  window.campusGymTrack = function (event, data) {
    // 例：自前の集計API や、プライバシーに配慮した解析ツールへ送信する
  };
</script>
```

導入時の注意：

- 個人を特定する情報（氏名・学籍番号・端末IDなど）は送らないでください。
- 計測を始めたら、`app.js` 内 `viewAbout()` のプライバシー説明を実際の内容に合わせて書き換えてください。
- 記録されるのはサイト上の操作であり、実際に運動したことを示すデータではありません。分析時もその前提で扱ってください。
