# キャンパス青空ジム

いつもの大学生活に、ちょっとした運動を。
大学構内のポスターのQRコードからアクセスし、短時間でできる運動（階段利用・ウォーキング・ストレッチ）を確認できる静的Webサイトです。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページの土台 |
| `style.css` | デザイン |
| `app.js` | 運動メニューの内容、画面切り替え、消費カロリー計算 |

HTML・CSS・JavaScriptのみで動作します。外部API・外部ライブラリ・外部フォントは使っていません。

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成します（例：`campus-aozora-gym`、Public）。
2. 「Add file」→「Upload files」で上の3ファイルと `README.md` をアップロードし、「Commit changes」を押します。
3. 「Settings」→「Pages」で Source を「Deploy from a branch」、Branch を `main`・フォルダを `/ (root)` にして保存します。
4. 数分後、`https://<ユーザー名>.github.io/campus-aozora-gym/` で公開されます。このURLをQRコードにしてください。

## 画面

- `#/` トップ（階段利用 → ウォーキング → ストレッチの順でカード表示）
- `#/stairs` 階段利用
- `#/walking` ウォーキング（消費カロリーの目安つき）
- `#/stretch` ストレッチ

各メニューのURLを直接QRコードにすることもできます（例：`.../campus-aozora-gym/#/stairs`）。

## 内容の編集

運動メニューの文言は `app.js` 冒頭の `MENUS` を編集してください。並び順がそのままトップの表示順になります。

## 消費カロリーの計算

消費カロリー（kcal）＝ 3.0（METs）× 体重（kg）× 時間（分）÷ 60 × 1.05

- 体重：40〜100kg、1kg刻みのスライダー（初期値60kgは計算用の仮設定）
- 3分間・5分間を同時に表示し、小数第1位まで表示
- 体重は保存・送信しません
- 設定値は `app.js` の `CAL` で変更できます

## グミ換算（ウォーキングのみ）

グミ換算（粒）＝ 推定消費カロリー（kcal）÷ 12.0

- 12.0kcalは、ピュレグミの栄養成分表示（1粒3.5gあたり）の値です
- 3分間・5分間それぞれの換算を小数第1位まで表示し、体重スライダーに合わせて自動更新します
- 例（体重60kg）：3分 約9.5kcal（グミ約0.8粒分）、5分 約15.8kcal（グミ約1.3粒分）
- 1粒あたりの値は `app.js` の `CAL.gummyKcal` で変更できます
- 商品の公式ロゴやパッケージ画像は使用せず、シンプルなイラストで表示しています
